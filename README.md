# btlib10x

A TypeScript library of BattleTech Total Warfare board game rules (a subset),
with a browser terminal app (`web/`) to play them. See `docs/CLI.md` for the
app and the rules covered, `docs/API.md` for the library, and `AGENTS.md` for
the commands and layout.
